# DreamPub v0.1.2

发布日期：待标签 `v0.1.2` 推送后填写。

## 本次更新

- Evan 和 Loopy 现在使用项目内置的透明背景像素精灵，而不是彩色方块占位符。
- 两个精灵根据用户提供的拼豆图纸提炼：Evan 保留深色外套与粉色围巾，Loopy 保留粉色垂耳兔轮廓与服装细节。
- 精灵在 Phaser 预加载，保留现有的实时位置同步、状态标签、座位占用与聊天气泡行为。

## 验证

- 前端 TypeScript 与 Vite 生产构建通过。
- 在本地 Dream Cafe 页面中确认两名 NPC 的精灵、状态标签与聊天面板可见且不重叠。

继承 [v0.1.1](v0.1.1.md) 的功能边界与已知限制。
