# DreamPub v0.1.1

发布日期：待标签 `v0.1.1` 推送后填写。

## 定位

这是 DreamPub 的第一个公开演示版本。它适合本地体验、角色设定实验和继续开发，不应被视为生产级专注记录工具。

## 新增与可体验内容

- 可游走的 Phaser 像素咖啡馆：座位、项目板、日夜视觉与 NPC 座位占用。
- 浏览器本地的项目、任务、甘特概览、专注记录与统计视图。
- Loopy、Evan 的确定性日程；可选 DeepSeek 驱动的活动建议和两句以内对话。
- 人物问卷工作室：12 个稳定问题、严格模板校验、首次苏醒台词、内容哈希去重和版本历史。
- FastAPI 的健康检查、世界快照、角色模板 API 与 WebSocket 状态流。

## 已验证

- `apps/web`: `pnpm build` 通过 TypeScript 检查并生成生产构建。
- `apps/server`: 人物模板、版本兼容、运行时回退和重复消息抑制测试。
- `contracts`: JSON Schema 与有效/无效示例校验由 CI 执行。

## 已知限制

- 没有认证、用户隔离或多人协作；世界 ID 与用户目标仍是演示固定值。
- 项目、任务与专注会话只保存在浏览器；NPC 运行记忆和实时状态只在服务进程内。
- 专注时长由浏览器时钟计算，不能作为可靠、跨设备或审计记录。
- WebSocket 没有鉴权、断线事件补发、持久事件日志或多实例协调。
- DeepSeek 调用不具备生产级预算、速率限制、审计和敏感信息策略；密钥缺失或调用失败时会回退。
- 前端没有单独做资源分块，生产包存在大于 500 kB 的打包提示。

## 部署说明

前端可部署到任意静态站点；设置 `VITE_NPC_SERVER_URL` 指向 HTTPS/WSS 的 FastAPI 服务。后端需要一个长驻的 ASGI 服务，并在 `ALLOWED_ORIGINS` 中显式配置前端域名。不要把 `apps/server/.env` 或 API 密钥上传到 GitHub。
